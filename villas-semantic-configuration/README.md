# VILLAS Semantic Configuration Tool

This package implements logic to convert the VILLAS node configuration files (see [spec](https://villas.fein-aachen.org/docs/node/config/)) to a semantic representation using rdflib.

## Credits

This package was developed as part of NFDI4Energy to produce simulation scenarios that conform to the [NFDI4Energy Co-Simulation Ontology](https://github.com/NFDI4Energy/simulation-scenario-ontology).
